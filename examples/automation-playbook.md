# 건축 자동화 작업 지침 템플릿
이 파일은 교육용 초안입니다. 설치된 스킬이나 새로운 프로그램 권한이 아닙니다.

## 적용
확정된 프로젝트 입력으로 개념 매스, 조감도, 기하학적 검수 보고서를 생성할 때 사용합니다.

## 입력
project_id, revision, 단위, 원점, 북쪽, 대지 크기, 건물 크기, 층수, 층고, 출력 폴더.
누락은 질문으로 돌려보내고 임의 가정은 별도 표시합니다.

## 순서
1. 입력 스키마와 양수·정수·범위를 검사합니다.
2. 대상 프로그램 버전, 전용 장면·그룹과 출력 폴더를 확인합니다.
3. 기존 원본을 보존하고 교육용 범위에서 생성합니다.
4. 실제 객체 치수와 입력을 비교합니다.
5. 고정 카메라·조명으로 렌더합니다.
6. 모델, 이미지, 입력값, 검수값을 함께 저장합니다.

## 검사
단위 혼동, 중복 객체, 높이·층수, 빠진 산출물, 오래된 모델 참조.
법규와 구조·피난 판단은 검증된 기준과 전문가 검토로 이관합니다.

## 실패
누락 입력은 생성 전 중단. API 오류는 단계와 버전 보고.
비용·사용량 제한은 추가 구매 없이 가능한 대체 경로 검토.
실행하지 않은 작업은 미검증으로 기록.

## 보고
성공·실패·미확인을 구분하고 파일, 변경 범위, 검사 결과, 남은 쟁점을 전달합니다.
